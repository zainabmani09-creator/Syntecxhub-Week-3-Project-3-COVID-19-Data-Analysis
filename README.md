# COVID-19 Data Analysis Project

## Objective
To perform Exploratory Data Analysis (EDA) on COVID-19 time-series data and
visualize trends using Python.

## Tools Used
- Python
- Google Colab
- Pandas, NumPy
- Matplotlib, Seaborn

## Dataset
Johns Hopkins University COVID-19 Dataset  
Loaded directly from GitHub using pandas.

## Visualization
A single representative visualization (7-day rolling average of confirmed
COVID-19 cases) was exported to highlight trends and country-wise comparison.

## Key Insights
- Weekly rolling averages smooth daily fluctuations.
- The US showed the highest peak among selected countries.
- India displayed multiple waves over time.
- Italy had early spikes followed by stabilization.
